📌 AWS S3 Static Website Hosting

📖 Project Overview

This project demonstrates how to host a static website using Amazon S3. A simple HTML page (index.html) was created and deployed to an S3 bucket. Static website hosting was enabled, and bucket permissions were configured to make the site publicly accessible.

⚙️ Steps Performed

Created S3 Bucket – with default settings and a unique bucket name.

Uploaded Website Files – uploaded index.html into the S3 bucket.

Enabled Static Website Hosting – under bucket properties, set the index document.

Configured Permissions – disabled "Block All Public Access" and enabled ACLs to allow public read access.

Accessed Website – used the S3 bucket endpoint to view the hosted site.
